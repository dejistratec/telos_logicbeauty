# 代行会社（自社）のプロファイル

営業代行を行う **自社** の情報。代行会社名義で送るときの署名・紹介文に使います。
クライアント固有の設定は `sales/clients/<slug>/outreach.md`。

| 項目 | 内容 |
|------|------|
| 会社名・屋号 | 【要記入】 |
| 担当者 | 【要記入】 |
| 所在地 | 【要記入】 |
| Web | 【要記入】 |
| メール／電話 | 【要記入】 |
| 一言で（代行会社としての紹介 1 行） | 【要記入】 |

## 代行会社名義の署名（メール・フォーム用）
```
━━━━━━━━━━━━━━━━━━━━
【会社名】（【クライアント名】 営業パートナー）
担当: 【氏名】
〒【郵便番号】【所在地】
Web: 【URL】
お問い合わせ: 【メール／電話】
本メールは営業目的でお送りしています。今後の受信をご希望されない場合は、
本メールにその旨をご返信ください。以後お送りしません。
━━━━━━━━━━━━━━━━━━━━
```

## 代行会社名義で送るときの原則
- 1 行目か 2 行目で「【クライアント名】のサービスをご紹介する立場」であることを明示する（第三者を装わない）。
- クライアントの価格・実績は `offering.md` にあるものだけを使う。
- 返信先を自社にするか、クライアントにするかは `outreach.md` §1 の設定に従う。
