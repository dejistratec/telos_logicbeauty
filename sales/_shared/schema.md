# `targets.csv` 列定義と分類の値（全クライアント共通）

各クライアントの `sales/clients/<slug>/list/targets.csv` が営業先リストの原本です（UTF-8、ヘッダー 1 行、1 社 1 行）。
Google スプレッドシートや Excel に出すときは `node sales/scripts/targets.mjs export` の出力（`list/targets.export.csv`、BOM 付き）を使います。

## 列

| 列 | 必須 | 意味 | 値の例・ルール |
|----|------|------|----------------|
| id | 自動 | 一意 ID（クライアント内で一意）。ファイル名の接頭にも使う | `T-0001`（`targets.mjs add` が自動採番） |
| 登録日 | 自動 | 追加した日 | `2026-10-08` |
| プラットフォーム | ✔ | 営業先を見つけた場所（**分類軸 1**） | 下記「プラットフォーム」から 1 つ |
| ソースURL | | 案件ページ・見つけたページの URL | 発注なび / ランサーズの案件 URL、検索で見つけた記事など |
| 企業名 | ✔ | 特定した企業・ブランド名。特定不能なら `（特定不能）業種+特徴` | `株式会社○○` / `○○（ブランド名）` / `（特定不能）都内アパレルD2C` |
| 業種 | | 営業先の業種（**分類軸 3 の 1 つ**） | クライアントの `config.json` の `industries`（空なら自由入力。下記の既定リスト推奨） |
| 所在地 | | 都道府県＋市区 | `東京都渋谷区` |
| 規模 | | 規模感 | `個人` / `小規模(〜10名)` / `中小(〜30名)` / `中堅(31〜300名)` / `大手(301名〜)` / `不明` |
| WebサイトURL | | 公式サイト | |
| Instagram | | アカウント（@付き）。複数は `\|` 区切り | `@brand_official` |
| LINE公式 | | 導線の有無 | `あり` / `なし` / `不明` |
| その他SNS | | X / TikTok / YouTube など | `x:@xxx \| tiktok:@yyy` |
| ニーズ要約 | ✔ | 相手が欲しいこと・課題を 1〜2 文で | 募集文の言葉をなるべく残す |
| 推奨サービス | ✔ | クライアントのどの商材を当てるか（**分類軸 2**） | `config.json` の `services[].id` を `\|` 区切り（主→副の順） |
| 属性タグ | | 自由タグ（**分類軸 3**） | 下記「属性タグ」を参考に複数を `\|` 区切り |
| ICPスコア | | 0〜100 | クライアントの `icp.md` の配点 |
| ランク | | A / B / C / 除外 | |
| 接触チャネル | ✔ | どこから連絡するか | 下記「接触チャネル」から 1 つ |
| ステータス | ✔ | 進行状態 | 下記「ステータス」から 1 つ |
| 次アクション | | 次にやること 1 行 | `提案文作成` / `送付` / `返信待ち(10/15 まで)` |
| 期限 | | 次アクションの期限 | `2026-10-15` |
| 調査メモ | | research ファイルのパス（リポジトリルートから） | `sales/clients/<slug>/research/T-0001_xxx.md` |
| 提案文 | | proposals ファイルのパス | `sales/clients/<slug>/proposals/T-0001_xxx.md` |
| 備考 | | 自由記述（除外理由・特定確度・注意点） | `特定確度: 中（屋号と所在地が一致）` |

## 分類の値

### プラットフォーム（見つけた場所）
`発注なび` / `ランサーズ` / `クラウドワークス` / `その他クラウドソーシング` / `Web` / `Instagram` / `X` / `紹介` / `展示会・イベント` / `その他`

### 推奨サービス
クライアントごとに `sales/clients/<slug>/config.json` の `services[].id`（`/sales-setup` が設定）。

### 業種（既定リスト。クライアントの `config.json` の `industries` で上書き可）
`アパレル・雑貨D2C` / `コスメ・美容商材` / `美容サロン` / `飲食` / `ウェルネス・フィットネス` / `クリニック・治療院` / `教育・スクール` / `不動産・住宅` / `ホテル・観光` / `小売・EC` / `製造` / `IT・SaaS` / `BtoBサービス` / `制作会社・代理店` / `士業・コンサル` / `ベンチャー・新規事業` / `その他`

### 属性タグ（複数可・自由。揃えるために以下を推奨）
- フェーズ: `立ち上げ` / `成長` / `成熟` / `リブランディング`
- 課題（クライアントの商材に合わせて増やす）: `SNS属人化` / `LINE未導入` / `広告非効率` / `集客弱い` / `リピート弱い` / `人手不足` / `業務が属人化` / `制作力不足` / `計測未整備`
- 商流: `EC併設` / `複数店舗` / `店舗型` / `オンライン完結` / `BtoB` / `BtoC`
- 変化: `新店` / `新商品` / `採用強化` / `資金調達` / `周年` / `移転` / `組織変更`
- 案件性質: `単発` / `月額` / `コンペ` / `下請け`

### 接触チャネル
`プラットフォーム応募` / `メール` / `問い合わせフォーム` / `Instagram DM` / `LINE` / `紹介` / `電話` / `未定`

ルール: プラットフォーム列が `発注なび` `ランサーズ` `クラウドワークス` `その他クラウドソーシング` の場合、接触チャネルは `プラットフォーム応募` を既定とする（規約上の直接取引禁止のため）。スクリプトが検証します。

### ステータス
`未着手` → `調査中` → `提案作成済` → `送付済` → `返信あり` → `商談中` → `受注` ／ `失注` ／ `保留` ／ `除外`

## 例（1 行）
```csv
T-0001,2026-10-08,ランサーズ,https://www.lancers.jp/work/detail/xxxxxxx,（特定不能）都内アパレルD2C,アパレル・雑貨D2C,東京都,小規模(〜10名),,,不明,,"投稿が続かず世界観がばらついている。月 8〜10 万円で運用を任せたい",service-a|service-b,成長|集客弱い|月額,78,A,プラットフォーム応募,調査中,提案文作成,2026-10-10,sales/clients/<slug>/research/T-0001_apparel-d2c-tokyo.md,,特定確度: 低（候補 2 社・確証なし）
```

## 外部連携（クライアントごと）
Google スプレッドシートの URL は各クライアントの `outreach.md` ではなく `config.json` の `"spreadsheet_url"` に記録します（`/sales-list Google スプレッドシートに出力` の初回実行時に追記）。
