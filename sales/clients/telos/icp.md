# TELOS — ICP（理想顧客像）と選定基準【記入済みサンプル】

`/sales-intake` `/sales-prospect` `/sales-qualify` はこのファイルの配点でスコアを出し、`list/targets.csv` の「ICPスコア」「ランク」を決めます。このリポジトリのサイト（TELOS）向けに記入した**記入例**です。
狙いを変えたいときはこのファイルだけを直し、`/sales-qualify all` で再ランク付けしてください。

## 1. 誰を狙うか

### コア（最優先）
| 軸 | 内容 |
|----|------|
| 業種 | アパレル・雑貨・コスメなどの D2C ／ 美容サロン・エステ・ネイル ／ 飲食（カフェ・レストラン）／ ウェルネス（ヨガ・パーソナルジム）／ ライフスタイル系の店舗・ブランド ／ 新規事業・ベンチャーのブランド立ち上げ |
| 規模 | 個人事業〜従業員 30 名程度。意思決定者（オーナー・代表・事業責任者）に直接届く距離 |
| 予算感 | 月額 ¥50,000〜¥150,000 を「投資」として出せる ／ 広告なら月 ¥25 万以上の広告費 |
| 価値観 | 「世界観」「ブランディング」「らしさ」「上質」「丁寧」を大事にしている。数字も気にするが安売りはしたくない |
| 状態 | Instagram は持っているが伸び悩み・属人化 ／ LINE 公式が無い or 放置 ／ 広告は出したことがあるが世界観が崩れた |

### サブ（条件付きで狙う）
- 制作会社・広告代理店からの下請け（`creative` 単発） — 価格競争になりやすいので「世界観の再現力」で選ばれる案件のみ
- BtoB サービス — 採用ブランディングや LINE での見込み客育成など、「ファン化」の文脈があるもののみ

### 除外（ランク「除外」）
- 予算が月 ¥30,000 未満、または「格安」「最安値で」が募集文の主旨
- アダルト・ギャンブル・情報商材・マルチ商法・医療広告ガイドラインを逸脱する訴求が前提のもの
- 自動フォロー・大量 DM・フォロワー購入など規約違反を求めるもの
- 撮影のみ・写真素材のみの依頼（TELOS のサービス範囲外）
- 競合（SNS 運用代行会社そのもの）の外注募集 — ただし `creative` 単発として明示的に判断した場合は可

## 2. 「買いたくなっている」シグナル（募集文・サイト・SNS から読む）

| 強いシグナル（+） | 弱いシグナル／注意（−） |
|------------------|------------------------|
| 募集文に「世界観」「ブランディング」「高級感」「統一感」「ファン」「リピート」 | 「とにかく安く」「量をこなせる人」「丸投げしたい」 |
| Instagram の投稿頻度が不定期 / 世界観がばらついている（伸びしろが明確） | アカウントが既に完成度高くフォロワーも多い（提案余地が小さい） |
| サイトに LINE 友だち追加の導線が無い・リッチメニューが無い | 大手代理店が既に運用（フッターやクレジットに社名） |
| 新店オープン・新商品・リブランディング・採用強化などの「変化」が直近にある | 事業の存続が不安定（閉店告知・休業） |
| 代表が自分の言葉で発信している（意思決定が速い） | 問い合わせ窓口が「営業目的のお問い合わせはご遠慮」と明記（送らない） |
| 複数店舗・EC 併設など LTV を伸ばす余地がある | 相手がすでに別の運用会社を募集文で名指し比較している |

## 3. スコア配点（100 点）

| 観点 | 配点 | 25 / 20 / 15 点の目安 | 0 点の目安 |
|------|------|---------------------|-----------|
| 予算適合 | 25 | 想定予算が TELOS の価格レンジに入る（25）／ 下限ギリギリ or 不明だが規模から妥当（15）／ やや下回る（8） | 月 ¥30,000 未満が明記 |
| サービス適合 | 25 | コア 4 サービスのいずれかにそのまま当たる（25）／ 組み合わせや調整で当たる（15）／ `creative` 単発のみ（10） | 範囲外（撮影のみ等） |
| 課題の明確さ | 20 | 課題と目的が募集文・サイトから読める（20）／ 推測は要るが仮説が立つ（12）／ 曖昧（5） | 何をしたいのか不明 |
| 相性（ブランド親和性） | 15 | 世界観・品質を重視し、TELOS の美意識と合う（15）／ 中立（8） | 価格訴求・量産志向で合わない |
| 接触可能性 | 15 | プラットフォームの応募枠が開いている / 問い合わせ導線があり営業 NG 表記なし / 意思決定者に届く（15）／ 窓口はあるが遠い（8） | 連絡手段が無い・営業 NG 明記 |

### ランク
| ランク | スコア | 扱い |
|--------|--------|------|
| A | 75〜100 | 48 時間以内に提案。文面は個別最適化を最大限行う |
| B | 55〜74 | 1 週間以内に提案。文面はチャネル別テンプレ＋固有の観察 2 点以上 |
| C | 35〜54 | 保留リスト。状況変化（新店・新商品など）を見てから |
| 除外 | 〜34 または除外条件に該当 | 理由を備考に書いて以後触らない |

### 補正ルール
- 除外条件（§1）に 1 つでも該当 → スコアに関係なく「除外」
- 企業特定の確度が「特定不能」 → 接触可能性は最大 8 点（プラットフォーム応募のみ可能なため）
- 「変化」シグナル（新店・新商品・リブランディング・採用強化）がある → +5（上限 100）
- 直近 6 か月以内に自分たちが提案して失注している → −10（`targets.csv` で確認）

## 4. スコアの書き方（research メモに必ず内訳を残す）

```
ICPスコア: 78 (A)
- 予算適合 20/25  : 募集文「月 8〜10 万円」→ instagram 推奨プラン(¥110,000)に近い。要調整
- サービス適合 25/25 : Instagram 運用 + LINE 構築の希望が明記
- 課題の明確さ 15/20 : 「投稿が続かない」「世界観を統一したい」と明記。KPI は未設定
- 相性 15/15 : サイト・投稿ともにミニマルで上質。TELOS と相性が良い
- 接触可能性 8/15  : ランサーズ経由のみ（特定確度: 中）
- 補正 +5 : 2 店舗目を来月オープン（Instagram 告知より）
→ 合計 88 → 上限丸め 88 (A)
```
