# /sales-list — リスト管理・分類・集計・出力・クライアント切替

入力: `$ARGUMENTS`（省略時は `集計`）

ツール: `node sales/scripts/targets.mjs --help`（clients / init / use / add / update / get / list / validate / stats / export）
列と許可値: `sales/_shared/schema.md`。クライアントの決め方は `/sales-intake` と同じ。

## 対応表
| 入力の意図 | やること |
|-----------|---------|
| クライアント一覧・今どのクライアント | `clients` を実行し、表で示す（* が既定） |
| 切替・このクライアントで | `use <slug>` |
| 集計・全体像・今どうなってる | `stats` を実行し、要約（件数、A/B の数、ステータスの偏り、期限切れ）＋ 3 行の所見 |
| 検証・おかしい行・重複 | `validate` を実行。エラーごとに修正案。明らかな誤記（許可値の表記ゆれ等）は `update` で直し、判断が要るものはユーザーに列挙 |
| 分類 <軸>（プラットフォーム／推奨サービス／業種／属性タグ／ランク／ステータス） | `list <列>=<値>` を値ごとに回して表で。「プラットフォーム × 推奨サービス」のクロス表は `stats` に含まれる |
| 更新 <id> 列=値 | `update`。ステータス変更時は `次アクション` と `期限` も合わせて更新（例: 送付済 → 返信待ち／7 日後）。research・proposal の frontmatter も同期 |
| 今週やること・期限 | `stats` の期限切れ表 ＋ `list ランク=A ステータス=未着手` 等を次アクション順に |
| 出力・Excel・CSV | `export` を実行し、`<C>/list/targets.export.csv` のパスを伝える（UTF-8 BOM、Excel でそのまま開ける） |
| Google スプレッドシートに出力／同期 | 下記 |

## Google スプレッドシート
1. `export` を実行する。
2. `<C>/config.json` に `spreadsheet_url` があれば**その同じファイルを更新**し、無ければ新規作成して `config.json` に `"spreadsheet_url"` を追記する。
3. 作成・更新は Google Drive コネクタ（`google-workspace` スキルの手順）で行う。コネクタが無い／権限が無い場合は、`targets.export.csv` を「ファイル → インポート」で取り込む手順を 3 行で伝える。
4. スプレッドシート側で人が編集した内容は原本（`targets.csv`）に自動では戻らない。戻すときは編集後の CSV を貼ってもらい `update` で反映する。

## 原則
- 原本は常に各クライアントの `targets.csv`。スクリプトを通さず手で CSV を書き換えない（列ずれ防止）。
- 行の削除はしない。不要になった行は `ステータス=除外` ＋ 備考に理由。
- 数字を報告するときは `stats` の出力をそのまま根拠にする。
- 別クライアントのリストと混ぜない（必ず対象クライアントを明示して報告）。
