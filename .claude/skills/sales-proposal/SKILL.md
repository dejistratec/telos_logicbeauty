# /sales-proposal — 営業文・提案文の生成

入力: `$ARGUMENTS`

## クライアントの決め方
`/sales-intake` と同じ。以降 `<C>` = `sales/clients/<slug>`。

## 先に読むもの（毎回）
1. `<C>/research/<id>_*.md`（無ければ先に `/sales-intake`、またはユーザーに原文を求める）
2. `<C>/offering.md`（価格・範囲・実績・NG 表現）
3. `sales/_shared/outreach_rules.md`（骨格・チャネル別・文体適応・法令）→ `<C>/outreach.md`（名義・署名・CTA・商材別「最初に起きること」・勝ちパターン）
4. 名義が代行会社なら `sales/_shared/agency.md`
5. `sales/_templates/proposal.md`／ `node sales/scripts/targets.mjs get <id>`

## 手順

### 1. 対象とチャネルを決める
- id または企業名で行を特定（企業名なら `list` で検索。複数あれば最も近いものを選び、そう述べる）。
- 主チャネルは引数の指定 → 行の `接触チャネル` → research の読み取り、の優先順。
- プラットフォーム経由の案件（発注なび／ランサーズ／クラウドワークス）は主チャネルを必ず**プラットフォーム応募**にする。
- 名義は `<C>/outreach.md` §1。`【要確認】` のままなら「クライアント名義」で書き、報告でその旨を伝える。

### 2. 材料を揃える（書く前に箇条書き）
冒頭フック（research §4 の固有の観察）／ 相手の言葉で書いた課題（引用）／ 推奨サービス（主→副）と `outreach.md` §4 の「最初に起きること」／ 価格・範囲・注記（`offering.md` そのまま）／ 実績 1 つ（相手の業種に近い方）／ CTA 1 つ（`outreach.md` §3）／ 文体設定（research §5 → `outreach_rules.md` §2）／ 想定反論と返し（`offering.md` §5）

### 3. 書く
- **A. 主チャネル用**: `outreach_rules.md` §0 の骨格順、§1 の文字数・形式・注意に従う。
  - ランサーズ／クラウドワークス: 冒頭 5 行で要件への回答（対応範囲・納期・金額・体制）。質問には全部答える。外部連絡先の誘導は書かない。
  - 発注なび: 範囲・金額・納期の表を入れる。
  - メール: 件名 30 字以内に相手固有の語。末尾に署名＋法令表記（プレースホルダーは空欄のまま）。
  - フォーム: 「営業のご連絡で恐縮ですが」と正直に。300〜500 字。
  - Instagram DM／LINE: 150〜250 字。感想 → 一言の自己紹介 → 会話を開く問い。提案の全部は書かない。
  - 電話: 60〜90 秒のトークスクリプト（話す順）。
- **B. 代替チャネル用**: 主と別のチャネルで短縮版を 1 つ。
- **C. 2 通目の骨子**: 「詳しく聞きたい」「予算が合わない」「今は不要」に各 1〜2 行。
- 文体ミラーリングは相手の 7 割まで。品位（短文・断定しない・貶さない）は保つ。

### 4. 自己チェック（保存前に必ず）
- [ ] 冒頭 2 行に固有の観察がある（テンプレのまま送れる文になっていない）
- [ ] 価格・範囲・注記・実績が `offering.md` と一致（創作していない／含まれないものを含むように書いていない）
- [ ] 「必ず」「保証」「No.1」「最安」が無い。`offering.md` §6 の NG 表現が無い
- [ ] 文字数がチャネル上限内（数える）
- [ ] 営業 NG 表記のあるサイトに送る文になっていない（research §3）
- [ ] プラットフォーム案件で外部連絡先の誘導をしていない
- [ ] 名義が明確（第三者を装っていない）。メール・フォームは署名＋法令表記あり

### 5. 保存・更新・報告
- `<C>/proposals/<id>_<slug>.md` に `sales/_templates/proposal.md` の構成で保存（slug は research と同じ）。
- `node sales/scripts/targets.mjs update <id> 提案文=sales/clients/<slug>/proposals/<id>_<slug>.md ステータス=提案作成済 次アクション=送付 期限=<明日>`
- チャットには **A（主チャネル用）だけ全文**、続けて「変えた理由（文体・切り口）」3 行以内、「送る前に人が埋める箇所」（署名・名義・【要確認】）を列挙。

## 禁止事項
- `offering.md` に無い価格・実績・サービス範囲。
- 相手の現状を否定する表現。
- プラットフォーム経由の案件で、外部での直接取引・連絡を促す文言。
- 署名・法令表記のプレースホルダーを勝手に埋めること。名義を曖昧にすること。
