# /sales-prospect — 営業先の発掘（公開チャネルから）

入力: `$ARGUMENTS`

## クライアントの決め方
`/sales-intake` と同じ（`--client <slug>` → `sales/clients/ACTIVE` → 候補が 1 つならそれ、複数なら質問）。以降 `<C>` = `sales/clients/<slug>`。

## 先に読むもの
`<C>/offering.md`（向いている相手）／ `<C>/icp.md`（コア業種・シグナル・除外）／ `sales/_shared/schema.md`／ 既存の `<C>/list/targets.csv`（重複回避。`node sales/scripts/targets.mjs list`）／ `sales/README.md` のルール

## 手順

### 1. セグメントを分解する
入力から **業種／地域／規模／欲しい状態（シグナル）／件数（既定 10）** を取り出す。足りない要素は `icp.md` のコアから補い、何を補ったかを 1 行で述べる（質問して止まらない）。

### 2. 候補を集める（WebSearch 中心、各クエリは目的を変える）
- 業種×地域のポータル・まとめ記事・業界団体の会員一覧（例: `渋谷 ネイルサロン おすすめ`、`○○市 製造業 一覧`）
- SNS 上の存在確認（`site:instagram.com <業種> <地域>` など）
- 「変化」シグナル（`<業種> <地域> オープン`、`リブランディング`、`新ブランド 立ち上げ`、`求人 急募`、`資金調達`）
- 公式サイトの有無と導線（問い合わせフォーム・SNS リンク・**営業 NG 表記**）
- 候補は **事業者**に限る。個人の私的アカウントは対象外。

### 3. 一次スクリーニング（1 社 1〜2 分で）
各候補: 公式サイト URL／SNS／規模感／ICP の強い・弱いシグナル／暫定スコア（`icp.md` の配点を粗く）／除外該当の有無。
`targets.csv` に同名・同 URL があれば外す。

### 4. 候補表を出し、保存する
- `<C>/intake/<日付>_prospect_<slug>.md` に、セグメント・使ったクエリ・候補表（企業名／URL／SNS／暫定スコア／理由 1 行／除外理由）を保存。
- チャットには上位候補を表で（企業名・暫定ランク・一言理由・接触チャネル）。

### 5. 上位を取り込む（提案文まで）
- 件数指定や「そのまま登録して」があれば、暫定 A/B の候補すべてについて `/sales-intake` の手順 3〜7 を実行する。`プラットフォーム` は検索で見つけたなら `Web検索`、SNS で見つけたなら `SNS`。企業は分かっているので候補（手順 2）は不要。提案文は直接連絡用だけ作る。
- 指定がなければ上位 3 件を取り込み、残りは候補表に残して「続けますか」と**最後に**一言添える（作業は止めない）。
- 最後に `/sales-list` の「スプレッドシートを更新」を 1 回実行する。

## 禁止事項
- フォロワー購入・自動フォロー・大量 DM を前提にした候補選定。
- 「営業目的のお問い合わせはご遠慮」等の表記があるサイトを接触可能として登録すること（記録はしてよいが `問い合わせ先` は空、`接触チャネル=未定`、備考に理由）。
- 担当者個人の連絡先を探すこと（記録するのは会社の公開窓口だけ）。
- ログインが必要な情報の取得。推測の数値を事実として書くこと。
